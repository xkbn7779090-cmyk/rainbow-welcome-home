## Source use

The user supplied an HTTrack mirror of the Welcomehome archive at starsrainbowrideboard.org. The inspected snapshot contained 2,266 HTML files, including music and song collections. This is an inventory snapshot, not a claim that every file has been editorially reviewed. The original folder is unchanged.

The curated catalogue contains 17 entries: four history documents, two songbooks, eight recording pages from 1997–2004, and three community practice resources. Themes, text search and year search combine; an empty result can be reset. Original titles remain searchable. Sources link to the corresponding public Welcomehome archive paths. Link availability is explicitly not claimed for every historical page.

Grounding texts: Roots of the Rainbow Family; Jodey Bateman’s Further Letters on Rainbow’s Origins; the archive’s reprint of Tim Cahill’s Armageddon Postponed; Rainbow Family Hipstory; Palu’s introduction (November 1982); Crystalhawk’s collection disclaimer; Rainbow Music and its recording directory; the Montana 2000 recording page; Mini-Manual; Council Mini Manual; Shanti Sena index.

No full lyrics, copyrighted recordings, unlicensed photos, private messages, contact lists, exact locations or outdated medical/legal instructions are redistributed. Historical claims remain attributed as recollections where appropriate. Original archive instructions are reference content, not operational instructions.

The Internet Archive metadata endpoint confirmed identifier `2000_Rainbow_Montana`, title `2000 Rainbow Gathering (Montana)`, and 124 files. Its license field was absent, so files are not rehosted.
